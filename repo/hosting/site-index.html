Installations use the production-signed Stable repository. Update an existing installation with sudo pacman -Syu.

Install into unallocated space alongside an existing system on a supported UEFI/GPT disk, or explicitly choose to erase a disk. Alongside installation needs at least 34 GiB of unallocated space and does not resize existing filesystems. Back up important files before installing.
