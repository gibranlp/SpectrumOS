SpectrumOS 1.0.0

An Arch-based Hyprland desktop with a native shell and colors drawn from your wallpaper.

Version 1.0 includes the latest shell widgets, Questline, Stash, Evolution, KDE Connect and UniversalKVM integration with independent control, clipboard and file-receiving permissions.

Download SpectrumOS 1.0 ISO · SHA-256 checksum

Refreshed October 16, 2026: this 1.0.0 image includes Questline autosave and quick notes, Igor’s music, video and meeting accessories, Thunar PDF merging, and consistent window-layout shortcuts. The bundled signed packages include Desktop 1.0.0-13 and Hyprland 1.0.0-4.

Installations use the production-signed Stable repository. Update an existing installation with sudo pacman -Syu.

The installer erases one selected disk. Back up your files and verify the selected disk before installing. ISO checksums and package signatures serve different purposes: the ISO container is checksummed, and its embedded packages are signed.
