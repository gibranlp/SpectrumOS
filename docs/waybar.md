# SpectrumShell bars

Waybar and its old layouts have been removed. SpectrumShell provides Standard, Minimal, Detailed, and Multimedia bars in top and left positions. Desktop package upgrades remove Waybar and mask its retired service. Shared telemetry, Cava, and workspace-icon helpers retain their existing filenames and settings so user preferences survive migration. See [SpectrumShell](spectrum-shell.md).
