# SpectrumOS 1.0.0

The current October 12 update (published October 13 UTC) uses Desktop 1.0.0-7 and SpectrumDrop 1.0.0-3. SpectrumOS owns and builds the maintained transfer/AWDL fork, preserving upstream licensing and Mac protocol compatibility. The desktop installs SpectrumDrop automatically; no `omdrop` or `omdrop-owl` packages or commands are required. Existing identities and settings migrate, with receiving off by default. Stable and Testing contain nine signed clean packages; all 28 public files per channel are verified over HTTPS. The full Python suite passes 701 tests with one expected skip, native checks pass, and local deployment is verified. Mac transfers after this migration still need physical retesting. Update with `sudo pacman -Syu`; ISO downloads are unchanged. See [SpectrumDrop](spectrumdrop.md) for architecture and test commands. Earlier release entries below retain historical package names and results.

The initial 1.0 release uses one immutable source snapshot for the six SpectrumOS packages. Incremental releases rebuild changed packages from their own checksum-verified snapshot and retain verified clean artifacts for unchanged packages, with production signatures and the normal Stable update path. UKVM and the temporary managed Hyprland portal retain their independent upstream versions.

The desktop includes the current SpectrumShell widgets and wallpaper-derived color system, smooth optional opening bounce, corrected shell curves and Escape handling, per-device audio volume controls, IPv4/IPv6 connection controls, packaged Kitty/Alacritty defaults, Igor's original-face sleep with paws and hover dismissal, Questline 2.0.1 and Stash 0.7.0 integration, Evolution, and KDE Connect with its tray indicator. UKVM provides independent input, opt-in text clipboard and opt-in secure file-transfer permissions, a native SpectrumOS widget and the Super+Shift+K shortcut.

Both Full and Lean installations install the signed desktop package, UKVM, the explicitly managed Hyprland portal, Questline and Stash. The installer retains its erase-one-disk, Btrfs and Limine workflow, laptop power-policy selection, graphics profiles and subsequent Stable updates. The release does not enable peer permissions, replace trust, automatically grant portal consent, or change existing personal settings.

Package validation, signed repository verification, ISO content inspection and VM boot/installation acceptance are recorded in project memory as they are completed. UKVM Linux input/persistence and bidirectional text clipboard are user-confirmed physically accepted. File transfer has a successful user-reported Spectrum-to-Hellgen send; the remaining M20 acceptance cases remain pending. A package or ISO build alone is not physical installation, hardware or reboot acceptance.

Known boundaries: the Hyprland partial external-edge InputCapture barrier limitation remains; the managed portal still carries the pinned upstream RemoteDesktop work; Windows/macOS UKVM backends are not implemented. The ISO supports the existing whole-disk installation workflow, not manual partitioning or same-disk dual boot. File transfer does not resume interrupted transfers.

Existing installations update with `sudo pacman -Syu`. Release identity is available through `spectrum info --json`; migration state can be inspected with `spectrum migrate status`.
